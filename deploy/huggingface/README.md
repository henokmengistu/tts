# Amharic TTS Studio

The [amharic-tts](https://github.com/henokmengistu/tts) server and web studio:
seven open-source Amharic voices (OmniVoice-Amharic 0.6B), with Gemini TTS and
Google Translate available for side-by-side comparison. On the free CPU tier a
sentence takes one to two minutes; a GPU Space answers in a few seconds.

Secrets (optional): `GEMINI_API_KEY` enables the Gemini comparison without the
viewer pasting a key.
